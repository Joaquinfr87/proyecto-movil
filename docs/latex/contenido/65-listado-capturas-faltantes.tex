\subsection*{Capturas que debes tomar}

Para completar las evidencias del avance 5, ejecuta la aplicaci\'on
en un dispositivo f\'isico o emulador y toma las siguientes capturas:

\begin{enumerate}
  \item \textbf{Pantalla de gesti\'on} (manage): muestra la lista de
    escenarios con los botones de editar y eliminar.
  \item \textbf{Formulario crear}: muestra el formulario vac\'io para
    crear un nuevo escenario.
  \item \textbf{Formulario editar}: muestra el formulario con los datos
    de un escenario existente precargados.
  \item \textbf{Eliminar escenario}: muestra el di\'alogo o acci\'on
    de eliminaci\'on suave.
  \item \textbf{Detalle con eventos}: muestra la pantalla de detalle
    con al menos un evento visible.
  \item \textbf{Crear evento}: muestra el formulario para agregar
    un nuevo evento.
  \item \textbf{Eliminar evento}: muestra la acci\'on de eliminar
    un evento existente.
  \item \textbf{Sesi\'on tras cierre}: captura de la app reabierta
    sin pedir credenciales (muestra el cat\'alogo directamente).
  \item \textbf{Favoritos persistentes}: captura de la pantalla de
    favoritos con al menos un escenario guardado.
\end{enumerate}

Reemplaza los archivos \texttt{.png} en \texttt{figuras/} con los
mismos nombres para actualizar el informe autom\'aticamente.
