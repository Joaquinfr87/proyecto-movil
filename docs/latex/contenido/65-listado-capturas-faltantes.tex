  \item \textbf{7 placeholders} (F16--F22): requieren screenshot real

    anteriores; idealmente deben reemplazarse con capturas nuevas del
    avance 5.
\end{itemize}

Del avance 6 (F25--F38) el estado es:

\begin{itemize}
  \item \textbf{Todas las capturas integradas} (F25--F38): incluyen las
    evidencias de operaciones con dos o tres paneles, los estados de
    carga y error en collages, y el listado de commits del repositorio
    (F38). No quedan capturas pendientes.
\end{itemize}

Las evidencias de operaciones (crear, actualizar, eliminar y datos
reales) est\'an integradas como collages de dos o tres paneles
(aplicaci\'on / buscador / Supabase), y los estados de carga y error
como collages de tres y cuatro paneles respectivamente. Si deseas
sustituir alguna imagen, reemplaza el archivo correspondiente en
\texttt{figuras/} con el mismo nombre y el informe se actualiza
autom\'aticamente.
