\subsection*{Capturas que debes tomar}

Del avance 6 quedan 14 capturas pendientes (F25--F38). Toma las fotos en
este orden y gu\'ardalas en \texttt{figuras/} con los nombres exactos de
la tabla anterior:

\begin{enumerate}
  \item \textbf{Proyecto Supabase} (evidencia6-proyecto-supabase.png):
    panel del proyecto con su configuraci\'on (URL y regi\'on).
  \item \textbf{Table Editor} (evidencia6-table-editor.png): todas las
    tablas creadas.
  \item \textbf{Estructura de tabla} (evidencia6-estructura-tabla.png):
    columnas y tipos de una tabla (p. ej. scenarios).
  \item \textbf{Registros} (evidencia6-registros-almacenados.png):
    filas de la tabla con los datos de prueba.
  \item \textbf{Configuraci\'on} (evidencia6-configuracion-proyecto.png):
    el \texttt{.env} y/o \texttt{src/services/supabase.ts}.
  \item \textbf{Conexi\'on} (evidencia6-conexion-establecida.png):
    salida de \texttt{pnpm supabase status} o sesi\'on activa.
  \item \textbf{Consulta de datos} (evidencia6-consulta-datos.png):
    una consulta devolviendo registros.
  \item \textbf{Datos reales} (evidencia6-pantalla-datos-reales.png):
    la app mostrando escenarios provenientes de Supabase.
  \item \textbf{Crear registro} (evidencia6-crear-registro.png):
    formulario de creaci\'on + registro guardado.
  \item \textbf{Actualizar registro} (evidencia6-actualizar-registro.png):
    edici\'on con el valor modificado.
  \item \textbf{Eliminar registro} (evidencia6-eliminar-registro.png):
    confirmaci\'on/resultado de la eliminaci\'on.
  \item \textbf{Estado de carga} (evidencia6-estado-carga.png):
    el indicador ``Cargando...'' de la app.
  \item \textbf{Estado de error} (evidencia6-estado-error.png):
    mensaje de error sin conexi\'on.
  \item \textbf{Repositorio} (evidencia6-repositorio-github.png):
    git log con los commits del avance.
\end{enumerate}

Reemplaza los archivos \texttt{.png} en \texttt{figuras/} con los
mismos nombres para actualizar el informe autom\'aticamente.
