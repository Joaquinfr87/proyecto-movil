\section{README del proyecto}

El archivo README es el documento de presentaci\'on de un repositorio de
software, en el que se describe el prop\'osito del proyecto, los requisitos de
instalaci\'on y la forma de ejecuci\'on, de modo que cualquier persona pueda
comprender y poner en marcha la aplicaci\'on \citep{githubdocs}.

El README del proyecto se elabor\'o en el lenguaje Markdown e incluye los
siguientes apartados:

\begin{itemize}
  \item T\'itulo del proyecto y breve descripci\'on de la aplicaci\'on
    \nombreApp{} y su prop\'osito.

  \item Requisitos previos: sistema operativo compatible, Node.js y la
    aplicaci\'on Expo Go en el dispositivo m\'ovil.

  \item Instrucciones de instalaci\'on, que describen la descarga del
    repositorio y la instalaci\'on de las dependencias del proyecto.

  \item Instrucciones de ejecuci\'on, que indican c\'omo iniciar el servidor de
    desarrollo de Expo y c\'omo abrir la aplicaci\'on en el dispositivo.

  \item Enlace al repositorio del proyecto en GitHub
    (\url{https://github.com/Joaquinfr87/proyecto-movil}).
\end{itemize}
