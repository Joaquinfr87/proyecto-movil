\section{Anexo B: Casos de uso}

Los casos de uso describen las interacciones entre los actores y el sistema
para cumplir un objetivo concreto \citep{kendall2011, larman2004}. En la
siguiente tabla se resumen los casos de uso principales identificados para la
aplicaci\'on m\'ovil.
